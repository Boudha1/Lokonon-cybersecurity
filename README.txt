SITE VITRINE — ANASTHASE LOKONON

1. Ouvrez index.html dans votre navigateur pour voir le site.
2. Pour publier : hébergez le dossier complet (index.html, styles.css, script.js, assets/) sur un hébergeur statique HTTPS, par exemple GitHub Pages, Netlify ou Cloudflare Pages.
3. Le site est un prototype de pré-lancement. Il n'est pas publié automatiquement et n'implique pas qu'une entreprise est immatriculée.
4. Avant la publication officielle, vérifiez les coordonnées, l'orthographe des diplômes, les services réellement proposés, les conditions contractuelles, les mentions légales, la confidentialité et l'hébergeur.
5. Le portrait est extrait du CV transmis : sa résolution est faible (108 x 146 pixels). Une nouvelle photographie authentique en haute résolution améliorera le rendu.
6. Les boutons de contact ouvrent l'application e-mail du visiteur ; aucun formulaire serveur n'est installé.
7. Aucune URL LinkedIn n'est affichée : l'adresse du profil n'a pas été vérifiée.
8. Police externe Google Fonts : pour une politique stricte sans ressources tierces, supprimer la ligne @import de styles.css (polices de secours prévues).
